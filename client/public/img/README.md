# Daftar Foto Komoditas Agro Maritim

Letakkan foto asli komoditas di folder `client/public/img/` dengan nama berkas mengikuti `produk_id` pada tabel `produk_komoditas`, serta foto latar hero utama.

| Nama Berkas | Peruntukan / ID Produk | Sektor | Keterangan |
| :--- | :--- | :--- | :--- |
| `hero-maritim.jpg` | Banner utama & slide pembuka | Umum | Pelabuhan ekspor dan lahan pertanian pesisir Nusantara |
| `slide-pertanian.jpg` | Slide pembuka & galeri beranda | Pertanian | Koperasi dan penyortiran panen kopi dataran tinggi |
| `slide-perikanan.jpg` | Slide pembuka & galeri beranda | Perikanan | Pelabuhan perikanan dan logistik rantai dingin ekspor |
| `slide-peternakan.jpg` | Slide pembuka & galeri beranda | Peternakan | Sentra peternakan sapi dan lahan hijau Nusantara |
| `1.jpg` | `produk_id = 1` | Pertanian | Biji Kopi Arabika Gayo Grade 1 |
| `2.jpg` | `produk_id = 2` | Perikanan | Tuna Sirip Kuning (Yellowfin Loin) Sashimi Grade |
| `3.jpg` | `produk_id = 3` | Perikanan | Udang Vaname Segar Ukuran Ekspor |
| `4.jpg` | `produk_id = 4` | Peternakan | Daging Sapi Potong Segar Grade A |
| `5.jpg` | `produk_id = 5` | Pertanian | Lada Hitam & Pala Banda Kering |

Catatan:
- Jika produsen mengunggah foto baru melalui formulir "Jual Hasil Panen", berkas disimpan di folder `/uploads/produk/` dan disajikan melalui `/uploads/produk/<nama_file>`.
- Format foto yang didukung: `.jpg`, `.jpeg`, `.png`, `.webp` dengan rasio aspek 4:3 untuk kartu katalog agar seragam.
